# 🗄️ قاعدة البيانات المركزية

## 🚀 كيفية تشغيل الموقع مع قاعدة بيانات حقيقية

### المتطلبات
- Node.js (مثبت على جهازك)
- اتصال بالإنترنت

### خطوات التشغيل

1. **تثبيت الحزم المطلوبة:**
```bash
npm install
```

2. **تشغيل الخادم:**
```bash
npm start
```
أو للتطوير:
```bash
npm run dev
```

3. **فتح الموقع:**
- الموقع الرئيسي: http://localhost:3000
- لوحة التحكم: http://localhost:3000/admin

## 📊 كيف تعمل قاعدة البيانات

### الملفات:
- `database.json` - قاعدة البيانات المركزية
- `server.js` - خادم Express.js
- `admin-script.js` - سكريبت لوحة التحكم المتصل بقاعدة البيانات

### المميزات:
✅ **بيانات مركزية** - جميع المستخدمين يحفظون في نفس المكان
✅ **وصول من أي جهاز** - البيانات متاحة من أي هاتف أو حاسوب
✅ **حماية كاملة** - لوحة تحكم محمية بكلمة مرور
✅ **تصدير البيانات** - CSV, JSON, طباعة
✅ **إحصائيات مباشرة** - عدد المشاركين والكشفيين

## 🔄 الفرق عن النسخة القديمة

### قبل (localStorage):
- ❌ البيانات تحفظ على كل جهاز بشكل منفصل
- ❌ لا ترى بيانات المستخدمين الآخرين
- ❌ كل مستخدم يرى بياناته فقط

### الآن (Database):
- ✅ جميع البيانات في مكان واحد
- ✅ ترى بيانات جميع المستخدمين
- ✅ بيانات حقيقية من جميع الأجهزة

## 🛠️ API Endpoints

- `GET /api/participants` - جلب جميع المشاركين
- `POST /api/participants` - إضافة مشارك جديد
- `GET /api/stats` - الإحصائيات
- `DELETE /api/participants` - حذف جميع البيانات

## 🔐 كلمة المرور
- لوحة التحكم: `admin123`
- يمكن تغييرها في ملف `admin-script.js`

## 📱 كيف يستخدمه المستخدمون

1. **المستخدم يفتح:** http://localhost:3000
2. **يسجل بياناته:** تحفظ مباشرة في قاعدة البيانات
3. **أنت ترى البيانات:** في لوحة التحكم فوراً
