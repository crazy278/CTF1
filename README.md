# أسبوع صاحب العصر والزمان

موقع ويب تفاعلي عن الإمام المهدي وكلام السيد الخامنئي، مع نظام تسجيل مشاركين.

## 🚀 كيفية النشر اونلاين

### 1. GitHub Pages (مجاني)
1. أنشئ حساب في [GitHub](https://github.com)
2. أنشئ مستودع جديد (repository)
3. ارفع ملفات الموقع إلى المستودع
4. في إعدادات المستودع، فعّل GitHub Pages
5. اختر المصدر (main branch) وسيكون الموقع متاح عبر: `https://username.github.io/repository-name`

### 2. Netlify (مجاني)
1. اذهب إلى [Netlify](https://netlify.com)
2. اسحب وأفلت مجلد الموقع
3. سيحصل على رابط فوري مثل: `https://random-name.netlify.app`

### 3. Vercel (مجاني)
1. اذهب إلى [Vercel](https://vercel.com)
2. استيراد المشروع من GitHub أو رفع الملفات
3. نشر تلقائي مع رابط دائم

### 4. Firebase Hosting (مجاني)
1. ثبّت Firebase CLI
2. نفّذ: `firebase init hosting`
3. ثم: `firebase deploy`

## 📁 ملفات الموقع
- `index.html` - الصفحة الرئيسية
- `style.css` - التنسيقات والتصميم
- `script.js` - الوظائف والتفاعلية
- `README.md` - هذا الملف
